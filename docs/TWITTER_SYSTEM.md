## 1. รูปแบบโครงสร้างข้อความ (Message Format Protocol)

ปลั๊กอินจะดักจับข้อความใน `CChat` ที่ขึ้นต้นด้วยคำนำหน้า `TW|` โดยแต่ละฟิลด์จะคั่นด้วยเครื่องหมายไพพ์ (`|`):

```text
TW|Name|Time|ProfilePic|Text|ImageURL
```

> **ข้อสำคัญ:** ห้ามมีช่องว่างหลังเครื่องหมาย `|` เว้นแต่จะเป็นเนื้อหาจริงของข้อความนั้น

---

## 2. รายละเอียดของแต่ละฟิลด์ (Field Specifications)

| ฟิลด์ (Field) | ตัวอย่างข้อมูล | คำอธิบาย |
| :--- | :--- | :--- |
| **`TW`** | `TW` | ส่วนนำหน้า (Header identifier) บ่งบอกว่าเป็นข้อความทวิตเตอร์ |
| **`Name`** | `@Somchai` หรือ `สมชาย ใจดี` | ชื่อผู้โพสต์ หรือ Handle Name (รองรับภาษาไทย / อังกฤษ / ตัวเลข) |
| **`Time`** | `10:30` หรือ `เมื่อสักครู่` | ข้อความระบุเวลาที่จะแสดงคู่กับชื่อ |
| **`ProfilePic`** | `https://i.imgur.com/xxx.png` | รูปภาพโปรไฟล์ แสดงผลในกรอบวงกลม (URL หรือไฟล์ในเครื่อง) |
| **`Text`** | `วันนี้มีปาร์ตี้ริมหาด Santa Maria!` | เนื้อหาข้อความทวิต (ตัดคำขึ้นบรรทัดใหม่อัตโนมัติ) |
| **`ImageURL`** | `https://i.imgur.com/event.gif` | *(ไม่จำเป็นต้องใส่)* รูปภาพแนบใต้โพสต์ หรือภาพขยับ GIF |

## 3. แหล่งที่มาของรูปภาพ (Image Sources & GIF Support)

ปลั๊กอินมาพร้อมระบบดาวน์โหลดและแคชรูปภาพแบบ Background Thread (`std::thread` + `URLDownloadToFileA`) ทำให้เกมไม่กระตุกขณะโหลดรูป:

### 1) รูปภาพจากอินเทอร์เน็ต (Direct Web URL)
ระบุ URL ที่ขึ้นต้นด้วย `http://` หรือ `https://`:
- **รูปภาพนิ่ง**: `.png`, `.jpg`, `.jpeg`, `.webp`
- **ภาพเคลื่อนไหว**: `.gif` (ปลั๊กอินจะทำการถอดรหัสทุกเฟรมและเล่นลูปต่อเนื่องอัตโนมัติ!)
- แหล่งอัปโหลดแนะนำ: Imgur, Discord CDN, หรือ Web Server ส่วนตัว

### 2) รูปภาพภายในเครื่องผู้เล่น (Local Client Assets)
หากไม่ใส่ `http://` หรือ `https://` ปลั๊กอินจะค้นหาไฟล์ในโฟลเดอร์ของเกม GTA:SA อัตโนมัติ:
```text
GTA San Andreas/models/txd/[ProfilePic หรือ ImageURL]
```
- เหมาะสำหรับการนำรูปโปรไฟล์เริ่มต้นมาติดไว้ในตัวเกมผู้เล่น เพื่อความรวดเร็วและไม่ต้องใช้อินเทอร์เน็ต

## 4. ตัวอย่างการส่งข้อความผ่านเซิร์ฟเวอร์ (Quick Examples)

### ตัวอย่างที่ 1: ทวิตเตอร์ข้อความธรรมดา (ไม่มีรูปแนบ)
```text
TW|Sompong_Hotdog|14:00|https://i.pravatar.cc/150?img=3|เปิดร้านฮอทด็อกหน้าอู่ช่างแล้ว แวะมาอุดหนุนกันได้ครับ!|
```

### ตัวอย่างที่ 2: ทวิตเตอร์พร้อมรูปภาพนิ่งประกอบ
```text
TW|@LSPD_News|15:45|https://i.pravatar.cc/150?img=12|ประกาศเตือนภัย มีเหตุปล้นร้านทองบริเวณ Market ขอให้ประชาชนระมัดระวัง|https://images.unsplash.com/photo-1541872703-74c5e44368f9
```

### ตัวอย่างที่ 3: ทวิตเตอร์พร้อมภาพเคลื่อนไหว GIF
```text
TW|Party_DJ|20:00|https://i.pravatar.cc/150?img=5|คืนนี้เจอกันที่คลับ Pig Pen มีดีเจรับเชิญพิเศษ!|https://media.giphy.com/media/l41lI4bYmcsPJX9Go/giphy.gif
```

### ตัวอย่างที่ 4: ใช้รูปภาพในเครื่องโฟลเดอร์ `models/txd/`
```text
TW|San_News|12:00|news_avatar.png|รายงานสภาพการจราจรรอบเมือง Los Santos วันนี้คล่องตัวดี|news_banner.png
```

## 5. รายละเอียดการเรนเดอร์ UI (Visual Features)

- **Dark Theme Card**: การ์ดพื้นหลังสีดำเข้มมนขอบระดับพรีเมียม (`IM_COL32(8, 8, 8, alpha)`)
- **Circle Avatar**: รูปโปรไฟล์ตัดขอบทรงกลมพร้อมเส้นขอบขอบสวยงาม
- **Smart Text Ellipsis**: หากชื่อผู้ทวิตยาวเกินขนาดการ์ด จะทำการตัดทอนด้วย `...` โดยอัตโนมัติเพื่อไม่ให้ทับเวลา
- **Dynamic Aspect Ratio Image**: รูปภาพประกอบจะถูกปรับอัตราส่วนกว้าง-ยาว (Aspect Ratio) ให้พอดีกับการ์ดอย่างสมดุล
- **Multi-Frame GIF Player**: อ่านเวลา Delay ของแต่ละเฟรมจาก GIF เพื่อความลื่นไหลระดับ 60 FPS
