## 1. รายการคีย์ลัดบนแป้นพิมพ์ (Keyboard Hotkeys)

| ปุ่ม (Key) | หน้าที่การทำงาน | เงื่อนไข / คำอธิบายเพิ่มเติม |
| :--- | :--- | :--- |
| **`T`** | เปิดหน้าต่างพิมพ์ข้อความ (Chat Input Box) | ทำงานเฉพาะเมื่อ**ไม่มี**หน้าต่าง SA-MP Dialog เปิดอยู่ (ป้องกันการพิมพ์ชน) |
| **`F6`** | เปิดหน้าต่างพิมพ์ข้อความ (Chat Input Box) | ทำงานทันทีโดยไม่มีเงื่อนไข (ตามพฤติกรรมดั้งเดิมของ SA-MP) |
| **`ESC`** | ปิดหน้าต่างพิมพ์ข้อความ (Chat Input Box) | ปิดทันทีและคืนการควบคุมตัวละครกลับสู่เกม |
| **`F2`** | ส่งคำสั่ง **`/f2`** ไปยังเซิร์ฟเวอร์โดยอัตโนมัติ | ปลั๊กอินดักจับคีย์แล้วส่ง `/f2` ทันที ผู้เล่นไม่ต้องกดเปิดแชทแล้วพิมพ์เอง |
| **`F3`** | ส่งคำสั่ง **`/f3`** ไปยังเซิร์ฟเวอร์โดยอัตโนมัติ | ปลั๊กอินดักจับคีย์แล้วส่ง `/f3` ทันที สะดวกสำหรับระบบเมนูหรืออนิเมชั่น |
| **`Page Up`** | เลื่อนดูแชทย้อนหลังขึ้นบน (**-5 บรรทัด**) | สามารถกดซ้ำๆ เพื่อดูประวัติการแชทย้อนหลัง |
| **`Page Down`**| เลื่อนดูแชทลงล่าง (**+5 บรรทัด**) | เลื่อนกลับลงมาหาข้อความล่าสุด |
| **`Mouse Wheel`**| เลื่อนดูแชทด้วยลูกกลิ้งเมาส์ | เมื่อชี้เมาส์ในบริเวณกล่องแชท สามารถเลื่อน Scroll ได้อย่างลื่นไหล |
| **`↑ (ลูกศรขึ้น)`** | ดึงประวัติคำสั่ง/ข้อความก่อนหน้า | ใช้งานขณะเปิดกล่องพิมพ์ข้อความ |
| **`↓ (ลูกศรลง)`** | ดึงประวัติคำสั่ง/ข้อความถัดไป | ใช้งานขณะเปิดกล่องพิมพ์ข้อความ |
| **`Ctrl + C / V / A`** | คัดลอก / วาง / เลือกข้อความทั้งหมด | รองรับ Clipboard บน Windows ภายในช่องกรอกข้อความ |

## 2. การทำงานของคีย์ลัด F2 และ F3

### เบื้องหลังการทำงาน (C++ Code)
ในไฟล์ `source/dllmain.cpp` ได้ทำการ Hook ฟังก์ชัน `Hooked_KeyPressHandler` ของ SA-MP เพื่อดักจับปุ่ม `VK_F2` และ `VK_F3`:

```cpp
if (nKey == VK_F2 && noMod && !IsSampDialogOpen()) {
    samp_utils::SendCommand("/f2");
    return TRUE;
}
if (nKey == VK_F3 && noMod && !IsSampDialogOpen()) {
    samp_utils::SendCommand("/f3");
    return TRUE;
}
```

### การนำไปใช้งานในเซิร์ฟเวอร์ (Server Pawn Script)
ทางฝั่งเซิร์ฟเวอร์สามารถสร้างคำสั่ง `/f2` และ `/f3` ในไฟล์ Gamemode/Filterscript เพื่อตอบสนองต่อการกดปุ่มของผู้เล่นได้ทันที เช่น:
- **F2**: เปิดเมนูช่วยเหลือหลัก (Help Menu), เมนูกระเป๋า (Inventory), หรือหน้าระบบเซิร์ฟเวอร์
- **F3**: เปิดเมนูยานพาหนะ (Vehicle Controls), เมนูอนิเมชั่น (Emote/Animation), หรือเปิดระบบวิทยุสื่อสาร

*(ดูตัวอย่างโค้ด Pawn เต็มรูปแบบได้ที่ [PAWN_INTEGRATION.md](PAWN_INTEGRATION.md))*

## 3. คำสั่งในช่องแชท (Built-in Chat Commands)

เมื่อพิมพ์ข้อความขึ้นต้นด้วย `/` ปลั๊กอินจะทำการตรวจสอบคำสั่งภายใน หากตรงกับคำสั่งที่กำหนดจะประมวลผลทันที และหากไม่ใช่จะส่งต่อไปยังเซิร์ฟเวอร์ SA-MP:

### คำสั่งตั้งค่าของปลั๊กอิน (Plugin Commands)
| คำสั่ง | คำอธิบาย |
| :--- | :--- |
| **`/setting`** หรือ **`/settings`** | เปิด/ปิดหน้าต่างตั้งค่า UI Chat (ความโปร่งแสง, มุมมน, แสดง Timestamp, รีเซ็ตตำแหน่ง) |

### คำสั่งมาตรฐานของ SA-MP Client (Dispatched Commands)
| คำสั่ง | คำอธิบาย |
| :--- | :--- |
| **`/timestamp`** | เปิด/ปิดการแสดงเวลาข้างข้อความ (บันทึกลง `sa-mp.cfg` อัตโนมัติ) |
| **`/pagesize [10-20]`** | ปรับจำนวนบรรทัดของแชท |
| **`/fontsize [-3 ถึง 5]`** | ปรับขนาดฟอนต์ของ SA-MP |
| **`/fpslimit [20-90]`** | ปรับขีดจำกัด Frame Rate |
| **`/headmove`** | เปิด/ปิดการหันศีรษะของตัวละคร |
| **`/audiomsg`** | เปิด/ปิดการแจ้งเตือน Audio Stream URL |
| **`/nametagstatus`** | เปิด/ปิดสถานะรูปนาฬิกาทรายเหนือศีรษะเมื่อพับจอ (AFK) |
| **`/savepos`** | บันทึกพิกัดตำแหน่งปัจจุบันลงไฟล์ `savedpositions.txt` |
| **`/interior`** | แสดงหมายเลข Interior ปัจจุบัน |
| **`/debug`** | เปิด/ปิด Debug Labels |
| **`/camera`** | เปิด/ปิดป้ายชื่อเป้าหมายกล้อง |
| **`/q`** หรือ **`/quit`** | ออกจากเกม GTA:SA ทันที |

## 4. ระบบประวัติคำสั่ง (Command History System)

1. **บันทึกอัตโนมัติ**: ทุกครั้งที่มีการส่งคำสั่ง (ข้อความที่ขึ้นต้นด้วย `/`) ปลั๊กอินจะบันทึกเก็บไว้ใน `m_ownHistory` (สูงสุด 10 คำสั่งล่าสุด)
2. **ปุ่ม Quick-Pill**: ใต้กล่องแชทจะมีปุ่มลัดของคำสั่งล่าสุดแสดงผลอยู่ ผู้เล่นสามารถคลิกที่ปุ่มเพื่อเรียกคำสั่งนั้นมาใส่ในกล่องพิมพ์ได้ทันที
3. **เลื่อนด้วยลูกศร**: สามารถกดปุ่มลูกศรขึ้น (`↑`) และลง (`↓`) เพื่อวนดูคำสั่งที่เคยพิมพ์ไปแล้วได้สะดวกรวดเร็ว
